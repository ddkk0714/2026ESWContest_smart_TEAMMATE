# DESKMATE UI 결정 사항 (V17 기준, 2026-10-25)

V1~V17을 거치며 확정한 내용이다. 버전별 변경 이력은 [README.md](README.md),
버전 목록은 [UI_DEMO_VERSIONS.md](../UI_DEMO_VERSIONS.md)에 있다.

## 범위와 경계

- UI 전용 앱이다. 센서·MQTT·HTTP·블루투스·카메라·키 입력 수집·원시 ToF·파일 로깅·
  실제 조명/선풍기/음악 제어·모델 학습은 연결하지 않는다. 앱 권한은 비어 있다.
- 프로필·설정·피드백·기록은 메모리에만 있고 앱을 종료하면 초기화된다.
- 제품 FSM 설정(`hub/deskmate_hub/config/*.yaml`)은 바꾸지 않는다. UI 대기 시간 등은
  `assets/config/demo.json`에만 둔다.

## 표시 규칙

- 화면·툴팁·팝업·리포트·앱 이름에 `UI 시연`, `시연`, `데모`, `Demo`, `mock`, `sample`,
  `예시` 같은 표시를 넣지 않는다. 구현 한계는 소스·문서에만 적는다 (AGENTS.md).
- 앱 표시 이름은 `DESKMATE V<N>`. 내부 앱 ID의 `ui_demo` 부분은 그대로 쓴다.
- DESKMATE 로고와 화면 버전 배지는 넣지 않는다 (V3 배지 제거, V13 로고 제거).
- 일반 화면과 어두운 집중 화면 모두 우측 상단에 앱 종료(X) 버튼을 둔다.

## 화면 구성

- 홈: 위에서부터 오늘의 한 줄 → 중앙 시계 → 날짜. 하단 한 줄에 공기·실내·자세·컨디션.
- 시계를 누르면 집중 시작. 하단 상태 항목 또는 왼쪽 스와이프로 멀티 위젯 진입.
- 집중 화면은 어두운 시계. 시작 안내는 5초 뒤 사라진다. 시계를 누르면 상세가 열리고
  10초 동안 조작이 없으면 다시 어두워진다. 멀티 위젯은 30초 동안 조작이 없으면 이전 화면으로 돌아간다.
- 멀티 위젯은 PR #56 원본 기반이다. 좌측 선택바는 없고, 타일을 눌러 상세로 들어가며
  상단 `홈으로`로 돌아온다.
- 색·글꼴: 크림·초록 팔레트, High1·LGText·LGClock 글꼴을 기본 화면과 위젯 모두에 쓴다.
- 시작 제안과 피로 제안은 화면 중앙의 밝은 카드로 띄운다.

## 화면 전환 (V17)

- 공통 전환은 움직임·크기 변화가 없는 밝기 디졸브다. 이전 화면은 500ms 동안 흐려지고
  새 화면은 같은 시간 동안 나타난다. 곡선은 easeInOut.
- 비교 후 채택: V14 페이드+작은 이동(280ms), V15 페이드 스루(300ms, 92%→100% 확대),
  V16 방향 가로 슬라이드(320ms)는 "슉슉 넘어가는 느낌"이라 V17로 대체했다.
- 메인 화면·위젯 상세·설정 탭·프로필 팝업이 같은 전환(`lib/page_transition.dart`)을 쓴다.
- 전환 중 이전 화면은 터치와 접근성 읽기를 막는다. OS의 애니메이션 최소화 설정을 따른다.

## 제안 카드 (V15 버그 수정)

- 피로 제안 카드는 `다른 방법`·`좋아요`·`도움 됐어요` 중 하나를 누르면 바로 닫히고
  답변 문구만 상단에 5초 표시한다. V8~V14에서는 답변 문구를 제목으로 단 카드가
  버튼과 함께 5초간 남았다. 회귀 테스트: `test/demo_test.dart`
  `fatigue card closes after either feedback answer`.

## 프로필

- 시계 위 팝업에서 선택한다. 항목은 이미지 아래 이름만 표시하고, 2열·짝수 슬롯이며
  마지막 슬롯은 항상 새 프로필 등록이다.
- 등록은 같은 팝업 안에서 한 질문씩 진행한다: 이름 → 이미지 → 작업 → 나이 → 수면 →
  도움 순서 → 소리 → 컨디션. 마지막에 한 번 저장하고 환영 화면을 보여준다.
  완료 전에 닫으면 저장하지 않는다.
- 이름은 랜덤 한글 별명이 미리 들어가고 다시 뽑을 수 있다. 최대 16자.
- 이름 입력은 앱 내부 한글·영문 키보드를 쓴다. Pi5에서 Atlas 시스템 키보드가 열린 지
  약 30ms 뒤 닫히는 현상이 재시도·입력 제어 조정으로 해결되지 않았기 때문이다.
  받침·복합 모음·삭제·띄어쓰기를 지원한다. OS·IME 설정은 바꾸지 않았다.
- 프로필 이미지는 Twemoji(CC BY 4.0) 8종이다. 출처·라이선스는 `assets/avatars`에 있다.

## 개인화 설정

- 우측 톱니바퀴 또는 프로필 팝업에서 연다. 탭 4개: 빛과 바람 / 소리 / 몰입 / 나의 리듬.
- 조명·바람 시작 여부와 강도, 피로 시 강도, 소리 종류·볼륨, 집중 목표 5~120분,
  자동 시작·자동 환경 맞춤·시작 안내, 도움 순서, 프로필 정보를 조절한다.
- 복사본을 편집하고 저장할 때 해당 프로필에만 적용한다. 취소하면 원본을 유지한다.
- 새 프로필은 자동 맞춤이 켜져 있어도 확인 4회(`feedbackRounds`) 전까지는 먼저 묻는다.

## 시간 값 (`assets/config/demo.json`)

- 1초당 세션 60초, 작업 징후 지속 10초, 자동 진입 신뢰도 기준 0.7.
- 상단 안내 5초, 상세 화면 10초, 위젯 30초, 부재 유예 5초.
- 원문 기준(10분 지속, 재실 1·3분, 부재 5분)은 구현하지 않고 위 값으로 대체한다.

## 버전 운영

- UI를 바꿀 때마다 별도 앱으로 설치한다. 기존 앱을 새 화면으로 덮어쓰지 않는다.
- 새 버전을 시작하기 전에 현재 소스를 `ui_demo_versions/vN`으로 보관한다.
  `build/`, `.dart_tool/`, SDK, 로그, 생성물, AGENTS.md는 제외한다.
  보관본은 용량(버전당 약 17MB) 때문에 레포에 올리지 않고 개발 PC에만 둔다.
- 앱 ID·실행 파일·표시 이름·CMake·pubspec 버전을 함께 올린다.
- 이전 앱 삭제는 요청할 때만 한다. LG OS의 home/notification 앱은 종료하지 않는다.
- Pi 설치 후에는 반드시 `sync`를 실행한다. 갑작스러운 재부팅으로 설치 파일이
  0바이트가 된 적이 있다.

## 폰트 자산 주의

- LG EI 폰트(`LGEIText*`, `LGEIHeadlineVF`)는 담당자 지시로 유지한 기존 자산이다
  (`assets/fonts/NOTICE.md`). 공개 레포 배포 가능 여부는 팀에서 확인이 필요하다.
