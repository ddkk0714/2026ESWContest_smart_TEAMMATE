1. 기본 화면

작업에 깊게 들어가지 않았을 때 (데스크 위에서도 항상 그 화면)

(진입 조건) : 항상 화면 노출

(내부 실행 흐름) :

a) 온습도, 조도, Co2, mmWave 센서는 데이터를 계속 수집 중.

b) 재실 1분 이상 (ToF 자세 판정 시작, 학습용 센서 데이터 로깅 시작

FSM: 부재 → 시작 (사용자에게는 알리지 않음)

c) 재실 3분 이상 \+ 작업 징후(키스트로크 발생, 또는 ToF상 전방 기울임 자세 유지)이면

d) 부재 N분 이상 (예: 5분 유예) 이면

* ToF 끄기, 학습 로깅 중단, FSM은 부재로 전환, 센서 조절 (조명 Off, 선풍기 Off)

(UI 디자인) :

**메인 중간 :** 디지털 시계

상단 : 오늘의 한줄 (따뜻하게\~, 용기를 북돋아줄 수 있게, 허리 피자, 인생 피자. 웃음꽃 피자.)

하단 1줄 : 정보를 최대한 줄이되, 누르면 상세 내용을 확인할 수 있도록. 방안 상태, 센서값, 피로도 등을 픽토그램으로 표현함.

2. 집중 화면

작업에 깊게 들어갔을 때 화면에 표시되는 화면

(진입 조건) :

제안 진입**:** 기본 화면의 제안 카드를 수락

* 초반 3\~4회는 매번 제안해서 라벨을 수집함
* 이후에는 신뢰도가 0.7 이상이면 (10분 지속 / 시연장에서는 10초 지속) 자동 진입하고, 화면에 "집중 모드 시작됨"만 작게 5초 표시

심사 시에는 (작업 시작 후 10초 만에 작업 상태 진입)

(내부 실행 흐름) :

학습용 센서 데이터 로깅 시작

피로·졸음 판정 시 (FSM: 몰입 → 피로/졸음)

* **프로필 선호 순서대로 개입함**
* 예) "졸 때 선풍기보다 LED 먼저" 선호 → LED 밝기·색온도 변화 → 그래도 지속되면 선풍기 플러그 ON

개입을 통해 개인화 라벨 수집.

(UI 디자인) : (기본) 어두운 화면에 디지털 시계만 나오도록 함.

(프로필 설정 시) 프로필 선호에 따라 조명 밝기·색온도 조정

예) 수험생 \= 종이·책 위주이므로 조명을 밝게

예) 재택 직장인 \= 모니터 위주이므로 눈부심이 덜한 쪽으로

(제안 카드) : 화면이 밝아지면서 제안 카드가 상단에 뜸.



3. 작업 종료 화면

종료 조건: 화면 터치 후 1단계 화면 출력 (작업 정리) \[종료\] 버튼, 또는 부재 N분 지속(일시정지 → 종료)

종료 시 동작: 조명 OFF 등 마무리 동작

1. 기본값은 사용자 설정
   2. 시연에서는 '시연 모드'로 시간 배속 \+ 즉시 소등

세션 요약: 집중 시간, 피로 구간, 환경 변화 등을 짧은 카드로 표시

3. 이 카드에서 "오늘 피곤했나요?" 같은 사후 라벨도 받을 수 있음

(UI 디자인)

* 1단계 화면
  * 경과 시간
  * 환경 센서 카드 (온습도·CO2·조도)
  * 자세 상태 (바름/기울어짐)
  * \[종료\] 버튼
* 2단계 화면
  * 경과 시간만 크게 표시하거나 거의 꺼진 화면
  * 터치하면 1단계 정보가 잠깐 나타남

4. 멀티 위젯

메모의 "사용자가 원할 때 나오는 부가 화면, TMI"에 해당함.

**(진입 조건)**

* 기본 화면이나 집중 1단계에서 스와이프 또는 버튼으로 진입
* 집중 2단계에서는 진입을 막거나, 길게 눌러야만 열리게 함 (방해 최소화)

**(내부 실행 흐름)**

* 이미 MQTT로 발행되는 토픽을 구독해서 보여주기만 함 → **FSM 판정에는 영향을 주지 않음**
* 30초간 조작이 없으면 이전 화면으로 자동 복귀
* 기기 수동 제어 기록은 학습용 피드백으로 저장
  * 예) 사용자가 조명을 직접 올림 \= 추천 밝기가 부족했다는 신호

**(UI 디자인)** — 타일형 위젯

* 센서 실시간 값과 최근 1시간 그래프 (CO2, 온습도, 조도)
* ToF 8×8 자세 히트맵 (시연 때 시각적 임팩트가 큼)
* 호흡 파형 ('실험적' 표기, 예선 피드백 반영)
* 오늘의 상태 타임라인 (부재/시작/몰입/피로/졸음 구간 막대)
* 기기 수동 제어 (LED, 스마트 플러그)
* 프로필·선호 설정

5. 프로필 설정 화면
   집중 화면 백색 소음, 카페 음악을 틀어주는 걸. 프로필 설정 시 질문.

### **5\. 시연 시나리오**

1. **개인화가 진행된 프로필로 시연** (예: 수험생)
   * 같은 졸음 상황에서 LED가 먼저 반응하고, 자동 진입·자동 개입 비율이 높음
2. **새 프로필 생성**
   * 선호도 조사 → 정보 수집 단계 (제안 카드와 "집중했어요?" 질문이 자주 뜸)
   * 시스템이 사용자를 배워가는 과정을 보여줌
3. **같은 입력 상황을 두 프로필에 넣어서 작동 차이를 대비**
   * 배속 모드로 진행

 (피드백 정책에 직접 반영)

* 직업 또는 주 업무
  * 수험생 → 종이·필기 위주 → 조명 우선, 키스트로크 가중치 낮춤
  * 재택 직장인 → PC 위주 → 키스트로크 가중치 높임
* 나이, 평균 수면시간
* 졸음 개입 선호 순서 (LED / 선풍기 / 알림)
* 선택 항목: 작업 시작 전 "오늘 컨디션" 1탭 입력

**학습용 페르소나**

* 학습할 때 페르소나를 여러 개 정의해 두면, 같은 상황에서도 반응이 다르게 나와서 개인화가 두드러져 보임

### **5\. 시연 시나리오**

1. **개인화가 진행된 프로필로 시연** (예: 수험생)
   * 같은 졸음 상황에서 LED가 먼저 반응하고, 자동 진입·자동 개입 비율이 높음
2. **새 프로필 생성**
   * 선호도 조사 → 정보 수집 단계 (제안 카드와 "집중했어요?" 질문이 자주 뜸)
   * 시스템이 사용자를 배워가는 과정을 보여줌
3. **같은 입력 상황을 두 프로필에 넣어서 작동 차이를 대비**
   * 배속 모드로 진행

\= 센서는 데이터를 계속 수집 중. (mmWave 판정을 한 다음에 ToF를 온한다. ToF 이외엔 다른 센서를 24시간 돌아가도 상관없음. 근데 학습을 위한 센서 수집은 mmWave 판정 이후에만 작동)

→ 시스템적으로 판단을 하되, 사용자에게는 알리지 않는다. (피로도 판단을 위한 자료 수집과 피드백 구조 루프) \= 초반엔 진짜 작업을 시작했는지에 대한 피드백을 받되 (3-4회), 이후엔 점점 줄여감.

\= 센서가 수집하는 값들 표시. 집중에 들어갔어요?

다른 조작 : 이 화면에서 사용자가 원하였을 때, 부가적인 화면이 나왔을 때. TMI

2단계 집중 : 이 상태에서 사용자가 깊은 작업을 들어가면 집중 방해 요소 없애기.

→ 프로필은 특별한 조작을 하지 않는 경우 유지.

→ (mmWave 재실판정 1분 이상 (알아서 시작할때 이떄 제안을 줄지), 사용자가 직접 작업 모드 실행. → 강제 실행)

2단계 : 작업 시작 초기 (여러 환경 센서 정보들 등등 표시)

\= 사용자가 작업을 종료하면 조명 등이 꺼진다. \= 시연 할 때만 이렇게 설정하겠습니다. (시간 빠르게 돌리기) 사용자가 설정할 수 있다. )

프로필 최초 생성시 선호도 조사를 받아서 피드백에 직접적으로 영향이 갈 수 있도록 하기. 졸 때 선풍기 보다는 LED를 먼저 켜준다.

1. 프로필에 따른 작동 예시가 다른 것을 보여주면 좋다.
2. 처음 프로필 만들 때 프로필을 상세하게 지정할 수 있도록 하면 좋을 것 같다. (오늘 기분을 작업 시작 전에 받거나, 직업이나 주로 하는 업무, 나이나 평균 수면시간 등)
3. ex) 수험생은 종이 연필을 만듦 (책을 주로 본다 → 조명을 밝게 해준다)
4. ex) 자택근무 직장인은 하나는 (PC, 데스크탑 → 키스트로크.)
5. 학습시 페르소나를 다양하게 지정해둔다. → 사용자 맞춤형이 더 두드러진다.

\= 우리가 시연을 먼저 줘야 한다. \= 이미 개인화가 많이 진행된 프로필과 아에 새로운 프로필을 설정. \= 새로 만들었으니까 정보를 수집하는 단계를 거칠 수 있습니다.
