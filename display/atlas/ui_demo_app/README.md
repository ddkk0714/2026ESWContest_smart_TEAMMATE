# DESKMATE V17

`UI에 대한 이모저모.md`를 화면과 조작으로 확인하는 독립 Atlas Flutter 앱이다.
원문은 [brief.md](brief.md)에 보관한다. 기존 화면의 집중·환경 흐름과 새 UI의
차분한 서체·타일을 조합했다. 기준 해상도는 Pi 5의 1024×600이다.

앱 ID: `com.atlas.app.deskmate_ui_demo_v17`, 표시 이름: **DESKMATE V17**.
기존 `DESKMATE`, `DESKMATE UI Test`와 별도로 설치된다.

## 실행해 보기

1. 기본 화면: 중앙 시계, 오늘의 한 줄, 아래 공기·온습도·자세·컨디션.
2. **중앙 시계 터치**: 집중 시작 후 어두운 시계. 시작 안내는 5초 뒤 사라진다.
3. 시계 터치: 경과 시간·온습도·CO₂·조도·자세·종료 버튼. 10초 무조작이면 다시 어두워진다.
4. **작업 종료**: 시간·피로 예시·마무리 카드와 선택형 사후 피드백.
5. **하단 상태 항목 / 멀티 위젯** 또는 왼쪽 스와이프: PR #56 폰트 수정본의 원래 멀티 위젯 화면으로 전환한다. 캘린더·시계·집중·날씨·실내·기기·설정 페이지와 길게 눌러 홈 위젯 편집을 사용할 수 있다. 상단 시계로 버튼으로 복귀한다. 30초 무조작 시 이전 화면으로 돌아간다.
6. 우측 상단 프로필 버튼: 시계 화면 위의 팝업에서 등록된 프로필을 선택한다. 각 항목은 이미지 아래 이름만 표시한다. 2열·짝수 슬롯(2·4·6·…)이며 마지막 우측 아래 슬롯은 항상 새 프로필 등록이다. 필요한 빈 칸은 비워 둔다. 슬롯이 많으면 스크롤한다.
7. 팝업 아래 프로필 관리 버튼을 누르고 이미지를 선택하거나, 등록창의 이미지 선택으로 동물·식물·추상·사람 이모지 8종 중 고른다. 이미지는 파스텔 배경으로 표시하고 선호·이미지는 데모 종료 전까지 유지한다.

## 발표용 시연 조작창

상단 조절 아이콘의 **발표용 시연 조작창**에서 프로필을 고르고 **재실·작업 상황 재생**을 누른다.

- 지우 / 개인화된 수험생: 10초 후 자동 집중 진입. 피로 입력 시 조명 → 선풍기 → 알림.
- 민준 / 개인화된 재택 직장인: 같은 입력에 자동 진입. 피로 입력 시 알림 → 조명 → 선풍기.
- 새 사용자 / 새로 만든 프로필: 시작 제안을 수락해야 진입한다. 피로 개입도 수락해야 모의 기기 상태가 변한다.
  시작 제안 수락·개입 피드백으로 확인 횟수가 4회가 되면 이후 자동 진입을 보여준다.
- **피로·졸음 상황**을 반복하면 다음 선호 방법을 보여준다.
- **부재** 입력은 경과 시간을 멈추고 5초 유예 후 종료한다. 유예 중 **돌아왔어요**로 복귀한다.

집중 중에는 프로필을 바꾸지 않는다. 종료 후 다른 프로필로 같은 입력을 재생해 비교한다.

## 시연 범위

모든 값·히트맵·파형·타임라인·신뢰도·학습 횟수는 **합성 예시**다.
센서, MQTT, HTTP, 블루투스, 카메라, 키 입력 수집, 원시 ToF, 파일 로깅,
실제 기기 제어·음악 재생·모델 학습은 연결하지 않는다. 앱 권한은 비어 있다.
ToF 8×8은 원문을 설명하는 합성 시각화이며 실제 VL53L9CX 해상도를 뜻하지 않는다.

프로필·선호·피드백·시연 기록은 메모리에서만 유지되고 앱을 종료하면 초기화된다.
직업에 따른 조명 및 개입 순서만 화면에 반영하며 실제 추론 가중치는 변경하지 않는다.
기본 상태에서는 자동으로 화면이 넘어가지 않는다. 시연 재생 또는 직접 시작을 눌러야 한다.

## 시간과 원문 해석

UI 전용 값은 `assets/config/demo.json`에 있다. 제품 FSM 설정은 변경하지 않는다.
시연은 1초당 세션 60초, 작업 징후 지속 10초, 자동 진입 신뢰도 기준 0.7,
개인화 예시 0.82, 새 프로필 예시 0.56이다. 원문의 운영 기준 10분 지속과
재실 1분·3분·부재 5분은 실제 구현하지 않고 시연 입력과 5초 부재 유예로 대체한다.
상단 안내 5초, 상세 화면 10초, 위젯 30초는 실제 UI 대기 시간이다.

원문의 중복된 ‘작업 종료 화면’ 1·2단계는 흐름 설명에 맞춰
**집중 상세 / 어두운 집중 시계**로 구현하고, 종료 후에는 별도 요약을 띄운다.
백색 소음·카페 음악은 선호 선택과 문구만 표시한다.

## 개발·검증

레포 루트를 `/workspace`로 마운트한 기존 Atlas 개발 컨테이너에서:

```sh
cd /workspace/.worktrees/ui-only-demo/display/atlas/ui_demo_app
flutter-atlas pub get --offline
flutter analyze --no-pub
flutter test --no-pub --reporter expanded
. "$ATLAS_FLUTTER_NDK_ENV"
flutter-atlas build atlas --no-pub --ipk --release
```

IPK: `build/atlas/arm64/release/ipk/com.atlas.app.deskmate_ui_demo_v17.ipk`.
화면 검토 PNG: `build/qa/{home,focus,details,widgets,report,profile}.png`.
SDK·생성물은 커밋하지 않는다. `preview_test.dart`는 실제 폰트로 여섯 화면을 렌더한다.

Pi 실행:

```sh
abusctl call com.atlas.AppManager1 Start com.atlas.app.deskmate_ui_demo_v17
```

되돌리기: 데모를 Stop 하고 기존 `com.atlas.app.deskmate_display`를 Start 한다.

우측 상단 X로 앱을 종료한다. 집중 화면에서도 사용할 수 있다.
버전별 보존 규칙은 [UI_DEMO_VERSIONS.md](../UI_DEMO_VERSIONS.md)를 따른다.

V3: 홈의 UI DEMO 배지를 제거하고 시계·날짜를 함께 위로 옮겨 시계를 화면 중앙에 배치했다.

V4: 시계 중심은 유지하고 응원 문구를 위, 날짜를 아래로 배치했다. 프로필 이미지 PNG는 Twemoji(CC BY 4.0)이며 assets/avatars에 원본·출처·라이선스를 함께 포함했다.
설치 후에는 sync를 실행해 디스크 기록을 완료한다. 전원을 끊기 전 OS 종료를 사용한다.

V5: 전체 화면 프로필 선택을 제거했다. 팝업 바깥 또는 X로 닫으면 시계가 유지되고, 프로필 선택 시에도 바로 닫힌다. 새 프로필만 등록 화면으로 이동한다.

V6: 조절 아이콘의 안내와 창 제목을 발표용 시연 조작창으로 통일했다. 피로·졸음과 부재 버튼은 항상 활성화된다. 대기 상태에서 누르면 시연 세션을 먼저 시작한 뒤 해당 상황을 보여준다. 진행 중인 세션의 경과 시간은 초기화하지 않는다.

V7: 임시 센서 타일 화면 대신 PR #56의 실제 DeskmateWorkspace를 통합했다. 로고는 Comic Neue다. 위젯 배치·설정·재생 상태는 앱 실행 중 메모리에만 보관하며 실제 음악·기기·네트워크 연결은 하지 않는다. 출처와 적용 범위는 lib/pr56/SOURCE.md 참고.

## V8 변경

멀티 위젯을 기본 화면과 같은 High1·LGText·LGClock 글꼴과 크림·초록 팔레트로 통일했다. 시작 제안과 피로 제안은 시계 위 화면 중앙의 밝은 카드로 표시한다. V7 소스와 설치 앱은 보존한다.

## V9 변경

집중 상세 화면의 경과 시계를 카드 중앙에 배치하고 책상 주변 카드를 자세 카드와 같은 크기의 아이콘·값 구성으로 맞췄다. 멀티 위젯 선택바를 제거했다. 각 타일에서 상세 화면으로 이동하고 상단 홈으로 버튼으로 복귀한다. V8은 별도 보존한다.

## V10 변경

프로필 선택 팝업의 새 프로필을 누르면 시계를 배경으로 같은 팝업에서 대화형 등록으로 전환한다. 이름·이미지·작업·나이·수면·도움 순서·소리·컨디션을 큰 글씨로 하나씩 묻고 뒤로 가서 수정할 수 있다. 마지막 답변에서 한 번 저장한 뒤 이름과 취향을 담은 환영 화면을 표시한다. 완료 전 닫으면 저장하지 않는다. V9 소스·설치 앱 보존.

## V11 변경

이름에 랜덤 한글 기본 별명을 미리 넣고 다른 별명 만나보기 버튼으로 다시 뽑을 수 있다.
이름 칸을 누르면 팝업 안에서 한글·영문 이름 키보드가 열린다. 두벌식 자모 조합,
복합 모음·받침·삭제·띄어쓰기·대소문자 전환과 16자 제한을 지원한다.
이름 지우기 X로 전체 삭제하며, 입력 완료는 키보드만 닫고 다음은 다음 질문으로 이동한다.
물리 키보드의 문자 입력·삭제도 처리한다.

Pi5 실기에서 Atlas 시스템 키보드가 열린 직후 약 30ms에 숨김 요청을 받는 현상을 확인했다.
타이밍 재시도와 기본 입력 제어 조정으로는 안정화되지 않아, 이름 입력에 한정해 시스템
키보드를 호출하지 않는 앱 내부 키보드로 교체했다. 기본 UI 색상과 글꼴을 사용한다.
V10 소스와 설치 앱은 보존한다. 외부 IME나 OS 설정은 변경하지 않았다.

## V12 개인화 세부 설정

기본 화면·집중 상세·멀티 위젯의 상단 톱니와 프로필 팝업의 나의 책상 설정에서 연다.
빛과 바람, 소리, 몰입, 나의 리듬 4개 탭으로 구성한다.
조명 시작 여부·밝기·빛 온도, 바람 시작 여부·1~3단계 세기, 피로 시 조명·바람 강도,
집중 소리 여부·종류·볼륨, 5~120분 집중 목표, 자동 시작·자동 환경 맞춤·시작 안내,
도움 순서, 프로필 이미지·작업·나이·수면·컨디션을 조정한다.
설정은 복사본을 편집해 저장 시 해당 프로필에만 적용하며 취소는 버린다.
집중 시작·피로 반응과 위젯의 목표·모의 음악 재생 상태에 연결한다.
새 프로필은 자동 맞춤이 켜져 있어도 충분히 알아가기 전에는 확인을 거친다.
모든 값은 UI 시연과 메모리에만 적용되며 실제 조명·바람·음악은 제어하지 않는다.
이 버전은 DESKMATE 상단 로고를 유지한다. 로고 제거는 다음 V13에만 적용한다.

## V13 로고 제거

V12의 개인화 설정을 유지하고 기본 화면·집중 상세·리포트·멀티 위젯 및 그 상세 페이지의 좌측 위 DESKMATE 로고를 제거했다. 프로필, 설정, 시연 조작창, 종료 버튼과 시계 위치는 유지한다. 로고가 있는 V12 소스와 설치 앱을 별도로 보존한다.

## V14 문구와 화면 전환

제품 화면·툴팁·보고서·앱 표시 이름의 시연·데모·예시 표시를 제거했다. 새 앱 표시 이름은 DESKMATE V14다. 앞으로도 해당 표현을 제품 UI에 추가하지 않도록 AGENTS.md에 기록했다. 메인 화면·위젯 상세·설정 탭·프로필 팝업 전환에 280ms 페이드와 작은 이동 효과를 적용했다. 이전 화면은 전환 중 터치와 접근성 읽기를 차단하며 애니메이션 최소화 설정을 따른다. 기존 시스템 팝업의 진입·종료 효과와 프로필 질문 전환도 유지한다. UI-only 하드웨어 경계와 메모리 저장 방식은 변경하지 않는다.

## V15 페이드 스루 전환과 제안 카드 닫힘

공통 화면 전환을 페이드 스루로 바꿨다. 이전 화면이 약 105ms 동안 먼저 사라지고, 새 화면은 300ms 전환의 35% 지점부터 92%에서 100% 크기로 커지며 나타난다. 메인 화면·위젯 상세·설정 탭·프로필 팝업이 같은 전환을 쓴다. 터치·접근성 차단과 애니메이션 최소화 설정은 유지한다. 피로 제안 카드는 `다른 방법`·`좋아요`·`도움 됐어요` 중 하나를 누르면 바로 닫히고 답변 문구만 상단에 잠깐 표시한다. 이전에는 답변 문구를 제목으로 한 카드가 버튼과 함께 5초 동안 남았다.

## V16 가로 슬라이드 전환

V15의 제안 카드 수정은 그대로 두고 공통 화면 전환만 가로 슬라이드로 바꿨다. 각 전환 지점이 화면 깊이(`order`)를 넘긴다. 더 깊은 화면으로 가면 새 화면이 오른쪽에서, 돌아가면 왼쪽에서 들어오고 이전 화면은 반대쪽으로 함께 밀려난다. 전환 시간은 320ms다. 메인 화면은 홈·집중·상세·멀티 위젯·리포트 순서, 설정은 탭 순서, 프로필 팝업은 선택→등록, 멀티 위젯은 홈→목록→기기 상세 순서다. 같은 깊이끼리는 앞으로 가는 방향으로 처리한다. 영역 밖으로 그려지지 않게 잘라 내고, 터치·접근성 차단과 애니메이션 최소화 설정은 유지한다.

## V17 밝기 디졸브 전환

움직임·크기 변화 없이 화면이 스르륵 바뀌도록 공통 전환을 디졸브로 바꿨다. 이전 화면은 500ms 동안 서서히 흐려지고 새 화면은 같은 시간 동안 서서히 나타난다. 둘 다 시작과 끝이 부드러운 easeInOut 곡선을 쓴다. V16의 방향용 `order` 값은 제거했다. V15의 제안 카드 수정, 터치·접근성 차단, 애니메이션 최소화 설정은 유지한다.
