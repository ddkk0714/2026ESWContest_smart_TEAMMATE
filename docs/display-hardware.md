## 규격

**Raspberry Pi 공식 7인치 DSI 터치스크린, 800×480.** HDMI 가 아니다.

| 항목 | 내용 |
|---|---|
| 연결 | DSI (MIPI) — 보드의 **`DISP`** 포트 |
| 케이블 | **22핀↔15핀 forward DSI FPC 어댑터** ("for Raspberry Pi 5" 표기 제품) |
| 터치 | **DSI 로 같이 온다.** 별도 USB 케이블 불필요 |
| 전원 | **분리 급전** — 보드는 USB-C PD 27W, 디스플레이는 자체 micro-USB |
| 해상도 | 800×480 (약 133ppi) |

## 함정

- **DSI 포트 오인** — 보드에 CAM/DISP 두 개의 22핀 포트가 있다. 디스플레이는 **DISP**.
  카메라용 케이블과 디스플레이용 케이블은 호환되지 않는다.
- **케이블 방향** — Pi 4 시절 유통된 **reverse 어댑터는 Pi 5 에서 동작하지 않는다.**
  15핀 1mm ↔ 22핀 0.5mm 라 물리적으로도 그냥은 안 꽂힌다.
- **GPIO 점퍼 급전 금지** — Pi 4 이하에서 쓰던 "디스플레이 보드 → GPIO 2·6번으로 급전"
  방식은 Pi 5 에서 전력이 모자란다. 반드시 각각 별도 전원.
- **조립 순서** — 전원 인가 전에 결선을 전부 끝낼 것. 디스플레이 micro-USB → 보드 USB-C
  순서로, **USB-C 를 가장 마지막에** 연결하면 그 시점에 부팅이 시작된다.

## UI 크기 제약

800×480 에서는 `1vmin` 이 **4.8px** 밖에 안 된다. 화면 크기를 순수 vmin/vw 로 잡으면
본문 글자가 8~9px 로 줄어 7인치 화면에서 못 읽는다.

→ `display/web/css/style.css` 는 크기를 전부 `clamp(px 하한, vmin, px 상한)` 토큰
(`--fs-xs` ~ `--fs-xl`)으로 잡았다. **순수 vmin/vw 로 되돌리지 말 것.**
터치 타깃(탭)도 `min-height:52px` 로 px 하한을 박아뒀다.

세로 설치로 회전하면 카드가 2열로 접히게 CSS 가 되어 있다.
단 **화면을 회전하면 터치 좌표도 같이 돌려줘야 한다** — 화면은 돌았는데 탭 위치가
어긋나면 이 문제다.

## 문제 해결

| 증상 | 확인 |
|---|---|
| 리본 케이블이 커넥터에 물리적으로 안 들어감 | 22↔15핀 **forward** 어댑터가 맞는지 |
| 화면이 아예 안 켜짐 | `DISP` 포트에 꽂았는지 (CAM 아님) · 디스플레이 전원 별도 연결 · FFC 래치 고정 |
| `Failed to open device: 'sdcard'` | 부팅 매체에 OS 가 없다. 그 카드가 데이터용은 아닌지 확인 |
| 빨간 LED만 켜지고 초록 LED 안 깜빡임 | 부팅 매체 인식 실패 또는 전원 부족. 27W 정격 확인 |
| 터치 좌표가 어긋남 | 화면 회전 후 터치 매트릭스 미회전. `libinput list-devices` 로 장치 확인 |
| 글자가 너무 작음 | CSS 크기 토큰이 clamp 인지 확인. 순수 vmin 이면 800×480 에서 8px 로 줄어든다 |
| 몇 분 뒤 느려짐 | `vcgencmd measure_temp` — 액티브 쿨러 미장착 시 스로틀링 |

```bash
vcgencmd get_throttled     # 0x0 이 아니면 전원·발열 문제
```
