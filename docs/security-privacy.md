# 보안·프라이버시 — 보고서용 초안 (W7)

> 기준일 2026-10-01. 개발완료보고서 "보안·프라이버시" 절과 발표 "왜 카메라·마이크를 안 쓰나" 슬라이드의 원고다.
> 멘토 피드백(09-22): **온디바이스·보안을 강하게 내세워라.** 문장마다 근거 파일을 달아 두었으니, 서술을 바꾸면 근거도 같이 확인한다.
> 비협상 제약 원문은 [`agent-briefing.md`](agent-briefing.md) §4, 데이터 보존 표는 [`data-spec.md`](data-spec.md) §12.

## 1. 한 문장

DESKMATE 는 **카메라·마이크 없이, 클라우드 없이** 책상 위 센서 값만으로 작업 상태를 판단하고, 판단·제어·기록을 모두 책상 안의 기기(ESP32·Pi 4·Pi 5)와 사용자 PC 안에서 끝낸다.

## 2. 무엇을 수집하지 않는가

| 수집하지 않는 것 | 대신 쓰는 것 | 근거 |
|---|---|---|
| **키 내용**(어떤 글자를 쳤는지) | 누름·뗌 **시각**과 종류 5가지(문자·공백·백스페이스·엔터·기타)만 → 60 s 창의 dwell·flight 통계, idle 비율, 수정 비율 | `collector/capture.py`(분류 후 키 객체 폐기), `collector/features.py`, `data-spec.md` §6.4 |
| **카메라 영상** | mmWave 레이더(재실·체동·졸음 상태), ToF 거리(예정) | 포스터·`agent-briefing.md` §4. ※ 개발용 ESP32-CAM 자세 판정이 저장소에 있다 — §6 미결 |
| **음성** | 없음(마이크 미탑재) | 하드웨어 구성 `hardware.md` |
| **ToF 원시 배열(54×42)** | 기하 특징만(운영). 원시 배열은 보정 모드에서만, 저장 금지 | `data-spec.md` §12 |
| **순간 심박·호흡 수치로 판정** | 중앙값·기준선 대비 "호흡 소실 여부"만 보조 증거, 기본 꺼짐 | `fsm.yaml` `respiration_enabled: false`, `fsm-spec.md` |

센서가 끊기면 값을 지어내지 않는다. 화면 요약은 끊긴 센서의 필드를 **생략**해 "없음"과 "모름"을 구분한다(`ingest/mapping.py sensor_summary`, `hub/tests/test_fault_scenarios.py`).

## 3. 어디에서 처리하는가 (온디바이스)

```text
ESP32 ─UART(COBS+CRC-16)─> Pi 4 hub ─MQTT(LAN, 이더넷 직결)─> Pi 5 화면
PC collector ─MQTT(LAN)─┘        └─> 스마트 플러그·램프(로컬)
```

- **판단**: 규칙 FSM 이 Pi 4 에서 돈다(판정 1회 PC 기준 p95 ≈ 0.6 ms, 예산 500 ms — `tools/measure_tick.py`). 2단계 분류기도 PC 에서 학습한 TFLite 를 Pi 4 에서 **추론만** 한다(`ml/README.md`).
- **통신**: 기기 사이는 유선 UART 와 로컬망 MQTT 뿐이다. 브로커는 Pi 4 의 Mosquitto 이고 외부 포트포워딩을 하지 않는다(`hub/mqtt/mosquitto.conf` 주석). 인터넷이 없어도 전체 기능이 동작한다(시험: `tools/rehearsal_local.py`, 브로커는 로컬 프로세스).
- **UART 무결성**: ESP32→Pi 4 프레임은 COBS 프레이밍 + CRC-16/CCITT-FALSE, 깨진 프레임은 버린다(`data-spec.md` §13.1, 09-16 실측 crc 오류 0).
- **제어**: 가역 동작만 자동으로 한다. 전원 차단 같은 비가역 동작은 사용자가 수락해야만 나간다(`control.yaml irreversible_operations`, `requires_confirmation`). 자동 실행은 60 s 안에 되돌릴 수 있다(`undo_window_sec`).

## 5. 사용자가 통제하는 것

- 모든 개입에 **이유**를 같이 보여 준다("CO₂가 높아요 (1180 ppm) · 방이 더워요") — `display/.../intervention.dart`.
- 확신도가 중간이거나 두 번째 원인을 시도할 때는 **묻고** 실행한다(제안 카드). 거절·무응답이면 아무것도 하지 않는다(`fsm-spec.md` 신뢰도 게이트, `gate.retry_max`).
- 판단이 틀리면 "지금 상태가 아니에요"로 정정한다. 정정은 판정을 바꾸지 않고 학습용 라벨로만 남는다(`esm.py`).
- 대기 화면에 "모든 처리는 이 기기 안에서 이뤄져요"를 상시 표시한다.

| 항목 | 현재 | 조치 |

| **카메라 자세 판정(I7)** | 개발용 ESP32-CAM + MediaPipe 판정이 main 에 있다 | 팀 결정. 권장: 시연·제출 빌드에서 제외하고 "개발 중 대역"으로만 서술(`roadmap.md` §3 I7). 그 전까지 이 문서의 "카메라 미사용"은 **제품 경로 기준**이다 |

| 저장소 공개 | Public 전환 예정 | 전환 전 시크릿·라벨 이력 스캔(`roadmap.md` §4-B 11) |

## 7. 발표용 세 줄

1. **보지 않는다** — 카메라·마이크가 없고, 키보드는 글자가 아니라 리듬만 본다.
2. **나가지 않는다** — 판단·제어·기록이 책상 위 기기 안에서 끝나고, 인터넷 없이도 돈다.
3. **묻고 한다** — 애매하면 제안하고, 자동으로 한 일은 이유를 보여 주고 되돌릴 수 있다.
