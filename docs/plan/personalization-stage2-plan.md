# 실센서 접근 전 개발 순서: 2단계 개인화

기준일: 2026-10-06 · 기준 코드: main `74d9cdf` (PR #35 병합).
통신은 사용자 확인으로 점검 완료로 취급한다.

## 현재 상태

- 완료: FSM, 중앙값/MAD baseline, ESM 정정 기록, 학습 창 생성·증강·세션 분할 및 약한 라벨 기준선 평가.
- 이번 작업 완료: 공통 모델 계약, 선택적 TFLite 관찰 추론, 오류 시 FSM 유지, 보드용 JSON 설정 패키징.
- 공통 1D CNN 학습 구현·실행 검증 완료: [학습 결과](../common-model-training.md).
- 개인 head 재학습·비교·폴백 구현 및 실행 검증 완료: [개인 head 결과](../personal-head-training.md).
- TFLite 변환·PC 수치 검증·실제 hub 관찰 추론 검증 완료: [변환 결과](../tflite-export-validation.md).
- 동일 프레임 관찰 비교·센서 누락 비교 도구 구현 및 실행 완료: [비교 결과](../model-replay-comparison.md).
- 미완료: Pi 4 native 런타임·실기 latency, 실사용자 정정 기반 검증, 팀 결정 이후 모델/FSM 결합.
- 개입 사이클 검증 도구는 별도 로컬 `feat/intervention-cycle-check` 작업이다. main 반영·실센서 검증 완료로 표시하지 않는다.

## 개발 순서와 완료 기준

1. **모델 계약과 hub 연결 기반** — 이번 개발 범위.
   - 기존 17개 특징 순서, 4개 클래스, 6 tick 창을 공유한다.
   - 관찰 모드에서 FSM 점수·상태·게이트·제어·리포트를 유지한다.
   - 비활성 기본값, 모델/metadata 누락·손상·불일치 및 추론 오류 폴백을 테스트한다.
   - 검증: 249 passed, 1 xfailed. 특징 일치·가짜 backend·제한 Python import·설정 패키징·회귀를 확인했다.
2. **PC 공통 모델 학습**.
   - 작은 1D CNN 후보부터 검토한다. 아키텍처 자체는 모델 계약에 고정하지 않는다.
   - 사용자/세션별 train/validation/test를 분리한다. 같은 세션의 겹친 창이 평가에 새지 않게 한다.
   - FSM 약한 라벨 일치율과 ESM 정정 라벨 성능을 나누어 보고한다. 합성 데이터 성능을 실제 집중도 정확도로 표현하지 않는다.
   - 완료 기준: 재현 명령·seed·출처·혼동행렬·macro F1·클래스별 recall·기준선 비교.
3. **backbone 동결 + 개인 head 재학습**.
   - 동의가 있는 PC 데이터만 사용하며 동의/저장 정책을 임의로 확대하지 않는다.
   - 별도 세션에서 공통 모델과 비교한다. 데이터 부족·편중·성능 악화 시 공통 모델을 유지한다.
   - 완료 기준: backbone 불변 확인, head 변화, 개인화 전후 비교 및 공통 모델 폴백.
4. **TFLite 변환과 PC 수치 검증**.
   - float32 입력 `[1,6,17]`, 확률 출력 `[1,4]`와 metadata를 만든다. 모델은 Git에 넣지 않는다.
   - 원본/변환 출력 오차와 top-1 일치를 검증하고 실제 모델 로딩·손상·shape/dtype 오류도 확인한다.
   - 완료 기준: 변환 재현 명령·모델 크기·latency·수치 오차 보고. ATLAS native 런타임 호환성은 보드에서 확인한다.
5. **관찰 비교 후 FSM 결합 설계**.
   - 같은 프레임 replay로 disagreement·저신뢰도·센서 누락을 평가한다.
   - `C_focus` 부호와 fusion 방식은 팀 결정 이후 구현한다. 모델 확률에 기존 행동 게이트를 바로 적용하지 않는다.
   - 완료 기준: 시간 조건·쿨다운·수락/거절/되돌리기·정정·리포트 회귀 및 모델 장애 시 FSM 유지.
6. **실센서 및 하드웨어 검증으로 복귀**.
   - 착석 → 집중 → 피로 → 제안 → 터치 수락 → 실제 제어 → MONITOR → 회복 → 리포트.
   - 수락·거절·무응답·되돌리기·정정, 센서 분리·브로커 재시작·화면 종료·인터넷 차단을 확인한다.
   - ToF 3분류·연결 경로, 스마트 플러그 모델, 자동 시작·UART 권한 복구, 하우징·발열·전원은 별도 실기 단계다.

## 가정과 남은 제한

- 후속 요청으로 공통 모델 학습과 개인 head 재학습까지 진행했다. 실제 사용자 효과는 미검증이며 TFLite 변환이 다음 단계다.
- 6 tick/17 특징은 기존 데이터 파이프라인을 따른다. 정규화 방식과 실제 tick 주기는 metadata와 hub 설정이 일치해야 한다.
- 기본 비활성이고 활성화해도 관찰 결과만 추가한다.
- 실모델·Pi 4 native 확장 호환성·성능·물리 제어는 미검증이다.
- 전체 저장소 자동 수집은 개발용 drop_test.py의 cv2 미설치로 실패했다. 명시적인 테스트 경로로 249개 통과를 확인했다.
