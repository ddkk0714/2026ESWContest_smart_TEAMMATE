## 서류 작성 기준 (2026-09-14)

- 서술 수준의 기준은 **UOS ECE Innovation Fair 포스터**(「DESKMATE : 카메라 없이 읽는 책상 위 인지 상태」)다.
  포스터 대비 구현 갭과 마감은 [`roadmap.md`](roadmap.md) §1~§3 을 따른다.
- 포스터 서술과 구현이 다른 항목은 **구현 기준으로 고쳐 쓴다**(`roadmap.md` §3):
  스켈레톤은 오프라인 검증·온보드는 기하 특징, mmWave 호흡·심박은 순간값 미사용, (신뢰도 주기는 09-14 에 10 s 로 맞춰 포스터와 일치)
  2단계 개인 헤드는 PC 학습 + Pi 4 TFLite 추론, 공기청정기는 ThinQ 1기기 선택.
- 실측 수치는 노션 기록을 인용한다: mmWave 117분 7,085프레임 체크섬 오류 0건, UART 26 B 프레임 1 Hz 도달(09-11).
- 개발완료보고서 20p 구성 초안: 개요·배경(2) / 하드웨어·통신(3) / 센서별 처리(4) / FSM·개인화(4) / UI·개입(3) / 시험 결과(3) / 결론·링크(1).

## 발표 대비 메모

- 결선 최대 배점은 **완성도(60점)**. ML 정확도보다 규칙 FSM + 실제 기기 제어의
  확실한 동작을 우선 시연한다.
- **"왜 음성 · 카메라를 쓰지 않는가"** 를 감시 부담 · 프라이버시 논리로 명확히 방어할 것.
  주최 예시(My Smart Sleep Guardian, Safety-Chef Agent)가 발화 인텐트 중심이라
  멀티모달 가산점에서 불리할 수 있다. 선택적 웨이크워드 / 음성 확인을 옵션으로
  열어 두는 것도 고려.
- 부스는 2m×2m. 실기기 물류 · 전력을 감안해 스마트 플러그 데모를 기본으로.
