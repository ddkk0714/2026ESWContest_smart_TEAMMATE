# DESKMATE 아키텍처

## 1. 계층 구조

### 센싱 레이어
- **ESP32 노드** — 책상 주변에 분산 배치. I2C/SPI 로 센서를 읽고
  노드 단에서 1차 전처리(이동평균 · 이상치 제거) 후 Wi-Fi MQTT 로 발행한다.
  - ToF `VL53L5CX` 8×8 zone, 15Hz — 재실 · 자세 · (보조) 호흡
  - `SCD41` CO₂ · 온습도, `BH1750` 조도
  - ToF 를 2개 이상 붙일 경우 `TCA9548A` I2C 멀티플렉서 사용
- **PC 수집기** — 키 입력 **타임스탬프만** 추출. 키 값은 수집하지 않는다.

전처리: ToF 4×4 다운샘플링, 신뢰도 낮은 zone 결측 처리, 중앙값 필터,
FFT · 자기상관 기반 호흡수 추출(30초 슬라이딩 윈도우), dwell · flight 타이밍 파싱.

### 추론 레이어 (Raspberry Pi 4)
- **1단계 — 규칙 기반 FSM**: 자세 클래스, 모션 변화율, 타이핑 공백 빈도를
  임계값으로 조합해 4개 상태(시작 · 몰입 · 피로 · 종료)를 판별하고 신뢰도 점수를 산출.
  완전 오프라인 동작. **완성도의 축.**
- **2단계 — 경량 분류기**: 자가기록 ESM 라벨로 학습한 CNN 2D / MLP 를
  TFLite 로 변환해 온디바이스 배포. 확신도 점수를 신뢰도 게이트에 입력하여
  1단계를 보완 · 검증한다.
- **신뢰도 게이트**: 신뢰도가 높으면 자동 제어, 낮으면 사용자 제안으로 분기.

### 출력 · 제어 레이어 (Raspberry Pi 5)
- 디스플레이: 현재 국면, 제안 카드, 휴식 알림, 작업 리포트, AOD
- 사용자 피드백(수락 · 정정) 입력 → 임계값 보정 · 재학습 라벨로 환류
- 제어: ThinQ API REST, 스마트 플러그, 조명, 환기팬

## 2. 신호 층위

사용자가 항상 키보드를 쓰지는 않으므로 신호를 두 층으로 나눈다.

| 층위 | 신호 | 가용성 |
|---|---|---|
| 바닥 신호 | ToF 자세 · 재실, 환경(CO₂ · 온습도 · 조도) | 항상 |
| 정밀 신호 | 키스트로크 dwell · flight · 공백 · 정정 빈도 | 키보드 작업 중에만 |

바닥 신호로 기본 추론을 수행하고, 키스트로크가 있을 때 신뢰도를 높인다.

## 3. 성능 목표

| 항목 | 목표 |
|---|---|
| 판정 사이클 | 500ms 이하 |
| ToF 취득 주기 | 15Hz (66ms) |
| 호흡수 추출 지연 | 약 30초 (슬라이딩 윈도우 FFT) |
| 모델 크기 | 수십 ~ 수백 KB (참조: ST HPD 5세대, Flash 29KB) |
| 오프라인 동작 | 1단계 FSM 완전 가능 / 2단계 TFLite 탑재 시 가능 / ThinQ 는 LAN 필요 |

## 4. 알려진 리스크

| # | 리스크 | 대응 |
|---|---|---|
| 1 | **ToF 호흡 측정** — 거리 노이즈(σ 수 mm~수십 mm)가 흉곽 미세변위와 비슷하거나 큼 | 호흡은 보조/스트레치 목표로 강등. 재실 · 자세가 주력. 8월 1주 실측 후 go/no-go |
| 2 | **ESM 라벨 부족** — 2개월 내 충분한 라벨 확보 어렵고 인지상태 정답 자체가 노이즈 | 2단계는 개념 실증으로 프레이밍. 1단계 FSM 이 완성도의 축 |
| 3 | **자세 → 인지상태 모호성** | 자세는 재실/자세종류 판정에만 제한 사용. 판정 주축은 키스트로크 + 작업시간 + 환경 |
| 4 | **CO₂ 인과 지연** — 수십 분 단위라 짧은 데모에서 상관 제시 어려움 | 맥락 신호로만 사용. 절대농도 구간(1000ppm 초과) 트리거는 환기 데모용 |
| 5 | **ThinQ API 의존** — LAN · 실기기 · NDA 필요, 부스(2m×2m) 물류 부담 | 스마트 플러그 + LED 스탠드/환기팬을 기본 제어 라인으로. 실 ThinQ 는 1개 기기만 시연 |
| 6 | **Pi 5 전원 · 발열** — 27W PD 어댑터 · 액티브 쿨러 사실상 필수 | 7/30 수령 시 27W 여부 · SD 용량 즉시 확인. Pi4 허브 역할을 Pi5 로 합치지 말 것(3종 HW 가산점) |
| 7 | **I2C 대역폭 · 주소 충돌** | ToF 는 raw 가 아닌 특징값만 MQTT 전송. ToF 2개 이상 시 TCA9548A |
