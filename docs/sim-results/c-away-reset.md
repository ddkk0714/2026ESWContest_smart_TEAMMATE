## 결론

- **보드 모델 opt_l8_c256(v4)에서는 `AWAY_RESET_S=0`(끔)**, 주기 리셋 `RESET_PERIOD_S=0` 도 끔. PR #72·보드 env 모두 0.
- 리셋 효과는 **모델에 따라 반대**다. v4 는 복귀 직후 문맥을 잃어 손해, v7b(opt_l8v5_c256)는 오래 비운 뒤 은닉 상태가 굳어 리셋이 도움.
- 보드 모델을 v5/v7b 계열(약한 끄덕임 보강 dz_v5 포함)로 바꾸면 다시 잰다.

## 리셋 규칙 (보드 df1e5f2 와 같음)

- 자리 비움 근거는 모델 출력 away 가 아니라 **ToF 규칙 재실(coverage)**: 센서별로 상태 5·6·9·10 이면서 150~1300 mm 인 zone 비율, 두 센서 중 큰 값 ≥ 0.06.
- 재실이 N s 연속 false 면 리셋(두 센서 GRU 은닉 상태 + EMA 비움, 워밍업 없음)하고, 비어 있는 동안 N s 마다 반복.
- 그래서 사람이 나가도 coverage 가 '재실'이면 리셋이 아예 안 난다. **[시뮬]** 배치 12개 중 6개(시드 1·3·5·7·8·12)가 비움 내내 재실 true. **[실측]** 자리 비움 60 s 2번 중 1번은 coverage 0, 1번은 0.38~0.44 로 내내 재실.
